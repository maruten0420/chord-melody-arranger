# 🎹 Chord Melody Arranger（コードに合わせてメロディーを改変）

コードのMIDIとメロディーのMIDIを読み込むと、**メロディーをコードに合わせて改変した案を複数**作るブラウザアプリです。
試聴して、良い案をMIDIで書き出せます。サーバー不要・ビルド不要の静的サイト（HTML/CSS/JS のみ）なので、GitHub Pages でそのまま公開できます。すべての処理はブラウザ内で完結し、ファイルは外部に送信されません。

## 主な機能

- **コード解析**: コードMIDIから約30種類のコード（7th / 9th / sus / dim / aug / 分数コードなど）を判定。判定結果は画面上で直接修正できます
- **自動移調**: メロディーのキーに合わせてコードを移調（手動指定も可）。移調後のコードMIDIも書き出せます
- **コードに沿った改変（6案＋ランダム）**: コードスケール・アヴォイドノート・強拍/弱拍・経過音の解決などを考慮した最適化
- **アレンジ**: 無・小・中・大の4段階。短く切る / 前後にずらす / 連打に分割 / 経過音 / 装飾音 / スウィング / アクセントを個別に選択
- **ハモリ生成**: 3度上下・6度上下・自動・コードトーン重視の6案
- **試聴**: ブラウザ上で再生（コード同時再生も可）。ピアノロール表示付き
- **MIDI書き出し**: 各案を `.mid` で保存

## 使い方

1. ① コードMIDI、② メロディーMIDIを選択（ドラッグ＆ドロップも可）
2. 自動で改変案が生成されます。カードの「▶ 試聴」で聴き比べ
3. 良い案の「⬇ MIDI出力」で保存

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリのルートに配置して push
2. リポジトリの **Settings → Pages** を開く
3. **Source** を `Deploy from a branch`、Branch を `main` / `/ (root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## ローカルで動かす

`index.html` をブラウザで開くだけで動きます。うまく動かない場合は簡易サーバーを使ってください。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 仕組みの概要

- MIDI は自前のパーサー/ライターで処理（外部ライブラリなし）。試聴は Web Audio API の簡易シンセです
- メロディー改変は、各音を±5半音の候補から選ぶ **ビタビ（動的計画法）** で、コード適合・元の音からの変更量・音程の動きの保存・経過音の解決をまとめて最小化します
- ハモリも同様に、メロディーとの音程（3度・6度優先）、コードとの適合、声部の滑らかさ、平行5度/8度の回避で最適化します

## 制限事項

- SMPTE形式のMIDI、ドラムチャンネル（ch10）は非対応です
- 拍子や弱起の変化は考慮していません（曲頭から小節が始まる前提で強拍を判定）
- ハモリは元のリズムのメロディーを基準に作ります（アレンジ後のリズムには追従しません）
- コード判定は簡易的なので、複雑な曲では画面上で修正してください
